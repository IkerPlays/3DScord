# Settings and themes

Open **Settings** from the menu (gear). **Y** searches inside the settings.

| Section | What is in it |
|---|---|
| General | Language, startup, accounts |
| Appearance | Theme, server icons, left-handed mode |
| Chat | Message display, images, GIFs |
| Controls and Battery | Push to talk, battery saver, keep awake |
| Voice | Microphone volume, noise gate, keep calls with lid closed, **Video (experimental)** (New 3DS / New 2DS XL only), ringtone |
| Updates | Auto-update, include devbuilds |
| Security and Backup | Accounts and backups |
| Discord Profile, Status, Chat, Privacy | Your Discord account: display name, About Me, pronouns, colour, avatar and banner (from files on the SD card), status and custom status |
| Advanced | Diagnostics, network test and more |

## Themes

Dark, Light, AMOLED, Nintendo, Retro and Midnight themes come with the app. There is a theme editor on the console, and you can write your own theme as a file: see
[THEME_FORMAT.md](https://github.com/IkerPlays/3DScord/blob/main/THEME_FORMAT.md).

## Languages

Many languages are included. Translations are in `romfs/lang/` and welcome as pull requests.
