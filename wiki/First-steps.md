# First steps

## Log in

- **QR code:** scan the code on the top screen with the Discord mobile app (Settings > Scan QR Code).
- **Email and password:** type them on the bottom screen.
- **`token.txt`:** create `sdmc:/3ds/3DScord/token.txt` with your token (plain text, no extra whitespace). The app reads it, logs in and deletes the file.

You can add more accounts and switch between them quickly from the settings.

> Never share your token or the `accounts` file in `/3ds/3DScord`. Either one gives access to your account.

## Controls

| Button | Action |
|---|---|
| D-Pad / Circle Pad | Move, scroll |
| A | Select, open the message menu |
| B | Back, cancel |
| Y | Search inside Settings |
| SELECT | Open the side menu |
| START | Exit |
| L + R | Debug overlay |

## The screens

- **Top screen:** the messages, or the people in the call.
- **Bottom screen:** the server and channel list, the message box and buttons (files, GIFs, stickers, pins, search, voice).
- **Side menu (SELECT):** Quick Access (saved messages, mentions, friends, voice), settings and about.
